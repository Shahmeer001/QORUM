# QUORUM frontend

A multi-page QUORUM decision-session demo built with React, TypeScript, TanStack Start, and Tailwind CSS. The demo uses local sample data.

## Run locally

Requirements: Bun (recommended) or Node.js with npm.

With Bun:

```sh
bun install
bun run dev
```

With npm:

```sh
npm install
npm run dev
```

Open the local address shown in the terminal. To make a production build, run `bun run build` (or `npm run build`).

The project includes the complete `src/` and `public/` folders plus its build, test, and styling configuration. Dependencies and generated build output are not included.
